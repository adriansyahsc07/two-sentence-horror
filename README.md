A horror story in exactly two sentences, written for make.fun's "Two-Sentence Horror" bounty. The program in this repository writes the story to `entry.txt` in the output directory: a prisoner who has spent twenty years counting the night patrol's footsteps past the cell across from his — a cell that was bricked shut in 1962 — hears something inside it count back. The dread is left implied; the second sentence is meant to make the first one worse every time it is re-read.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
